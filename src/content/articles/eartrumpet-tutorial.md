EarTrumpet replaces the Windows volume mixer with per-app control and quick device switching.

<!-- app:eartrumpet -->

## Installation

Install from Microsoft Store or `winget install File-New-Project.EarTrumpet`. It appears in the system tray. Click the icon to see all apps currently playing audio, each with its own volume slider.

## Daily Use

Click the EarTrumpet icon → adjust any app's volume independently. That browser tab blasting audio while your music is quiet? Fix them separately. Apps appear automatically when they play sound. Right-click an app to mute or route to a different audio device (headphones vs speakers).

## Device Switching

Click the device icon at the top to switch between speakers, headphones, USB headset, etc. Much faster than digging through Windows Sound settings. Assign the default device for communication vs media separately.

## Keyboard Shortcuts (Windows 11)

Windows 11's built-in volume popup (Win+Shift+V) now includes EarTrumpet-like per-app controls. But EarTrumpet adds:
- Assigning specific apps to specific audio devices
- Seeing audio levels visually for each app
- Quick access from the tray

## Tips

- Set EarTrumpet to replace the default volume icon: right-click taskbar → Taskbar settings → Notification area → "Select which icons appear" → hide Windows volume, show EarTrumpet
- Right-click EarTrumpet → Settings → enable "Start with Windows"
