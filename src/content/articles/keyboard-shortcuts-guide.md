The mouse is a bottleneck. Every time your hand leaves the keyboard, you lose seconds that add up to hours over a week. Here's how to minimize that.

## Universal Shortcuts

These work on both Mac (Cmd) and Windows (Ctrl):

| Action | Mac | Windows |
|--------|-----|---------|
| Copy | Cmd+C | Ctrl+C |
| Paste | Cmd+V | Ctrl+V |
| Cut | Cmd+X | Ctrl+X |
| Undo | Cmd+Z | Ctrl+Z |
| Find | Cmd+F | Ctrl+F |
| Switch apps | Cmd+Tab | Alt+Tab |
| Close window | Cmd+W | Ctrl+W |
| Quit app | Cmd+Q | Alt+F4 |

## Text Navigation

Hold Option/Alt while pressing arrow keys to jump by word. Hold Cmd/Ctrl to jump to line start/end. Add Shift to select while navigating.

## The Biggest Wins

1. **Cmd/Ctrl+Space** — Open launcher (Spotlight/Raycast/Win+Search)
2. **Cmd/Ctrl+Tab** — Switch between open apps
3. **Cmd/Ctrl+W** — Close current tab/window
4. **Cmd/Ctrl+T** — New tab (browsers, terminals, editors)
5. **Cmd/Ctrl+L** — Jump to address bar/search

## Building the Habit

Pick three shortcuts and use them intentionally for a week. When they become automatic, add three more. After a month, you'll wonder how you ever tolerated reaching for the mouse.
