LosslessCut performs lossless video operations — they're instant and preserve original quality.

<!-- app:losslesscut -->

## Basic Cutting

Open a video file. The timeline shows keyframes as small marks. Lossless cutting can only cut at keyframes, so cuts may be a few seconds off from your exact position. Use the seek buttons (left/right arrows below the preview) to jump to keyframes.

Set the **start** point (click the `[` bracket icon or press I). Set the **end** point (click `]` or press O). The selected segment turns green. Click Export (scissors icon).

## Extracting Segments

Select multiple segments by setting multiple start/end points. Each becomes a separate output file. Combine with the "Merge" option to join them into one video.

## Track Management

The "Tracks" panel lets you choose which audio and subtitle tracks to keep. Remove unwanted audio streams (director's commentary, foreign languages) to reduce file size. Add external subtitle files.

## Snapshots

Press the camera icon or Ctrl+S to capture the current frame as a PNG. Useful for thumbnails or reference images.

## Batch Processing

File → Batch. Process multiple files with the same cut points. Useful for episodes with the same intro/outro to remove.

Pro tip: For precise frame-level cuts, LosslessCut isn't the right tool — use a traditional editor. LosslessCut is for fast, rough trims without re-encoding.
