Greenshot is the lightweight screenshot tool that sits in your system tray and responds instantly.

<!-- app:greenshot -->

## Capture Modes

Right-click the tray icon or press Print Screen:
- **Capture region** — Drag to select an area
- **Capture window** — Click any window
- **Capture full screen** — Everything
- **Capture last region** — Repeat the last capture dimension

## Annotation Editor

After capture, the editor opens:

- **Arrow** — Emphasize things. Hold Shift for horizontal/vertical
- **Rectangle/Ellipse** — Highlight areas
- **Text** — Add labels
- **Obfuscate** — Blur sensitive text
- **Highlight** — Yellow semi-transparent overlay
- **Step numbers (1, 2, 3...)** — Create sequence steps
- **Crop** — Trim to selection

## Export Destinations

Configure in Preferences → Destination. Greenshot can send captures to: file (auto-save), clipboard, printer, email, and external applications. Enable multiple destinations — e.g., save to file AND copy to clipboard.

## Upload

Preferences → Plugins. Enable Imgur upload. After capture → "Upload to Imgur." The URL is copied to your clipboard. Also supports Box, Dropbox, Flickr, Jira, and Confluence.

## Quick Workflow

Set destination to "Clipboard" for instant pasting into chats and documents. Add "Save to file" with auto-generated filename. Now every Print Screen goes to both clipboard and disk automatically.
