macOS is great, but these free utilities fill the gaps Apple left behind.

<!-- app:rectangle -->
## Rectangle — Window Management

Snap windows with keyboard shortcuts. Halves, thirds, quarters. Free and open-source.

<!-- app:maccy -->
## Maccy — Clipboard Manager

Searchable clipboard history in your menu bar. Never lose a copy again.

<!-- app:appcleaner -->
## AppCleaner — Complete Uninstall

Deleting an app from Applications leaves behind preferences and caches. AppCleaner finds everything.

<!-- app:karabiner-elements -->
## Karabiner-Elements — Keyboard Customizer

Remap any key to anything. Essential for non-Apple keyboards or custom keybindings.

<!-- app:grandperspective -->
## GrandPerspective — Disk Space Visualizer

See your disk usage as a treemap. Giant cache folders and forgotten downloads jump out instantly.

## One-Line Install

```bash
brew install --cask rectangle maccy appcleaner karabiner-elements grandperspective
```
