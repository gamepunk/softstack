Setting up a new Windows machine? Install these free apps via winget and you're ready to go.

```bash
winget install Mozilla.Firefox
winget install Microsoft.VisualStudioCode
winget install VideoLAN.VLC
winget install Discord.Discord
winget install Valve.Steam
winget install TheDocumentFoundation.LibreOffice
winget install Obsidian.Obsidian
winget install Notion.Notion
winget install Audacity.Audacity
winget install GIMP.GIMP
```

<!-- app:firefox -->
## Firefox — Browser

Independent, privacy-first. Enhanced Tracking Protection blocks trackers by default. The only major browser not owned by an ad company.

<!-- app:visual-studio-code -->
## VS Code — Code Editor

The default editor for most developers. Extensions, Git, terminal, debugger — all integrated.

<!-- app:vlc -->
## VLC — Media Player

Plays everything. No codec packs, no ads, no tracking.

## Utilities

- **PowerToys**: Microsoft's free power user toolkit. FancyZones (window management), PowerRename, Keyboard Manager, and more.
- **QuickLook**: Press Space to preview files, macOS-style.
