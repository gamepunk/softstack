LibreOffice Writer is the free word processor that opens and saves .docx files.

<!-- app:libreoffice -->

## Essential Features

The interface is classic: menus at the top, formatting toolbar, ruler. It looks like Word 2003 but handles modern formats. Use Styles (F11) instead of manual formatting — consistent headings, body text, and captions across your document.

## Track Changes

Edit → Track Changes → Record. All edits are marked for review. Accept or reject changes in Edit → Track Changes → Manage. Comments: Insert → Comment (Ctrl+Alt+C). Used for collaborative editing.

## Export to PDF

File → Export As → Export as PDF. Options: choose image compression, embed fonts, add watermarks, and set PDF/A compliance (archival format). For a fillable form, create form fields (View → Toolbars → Form Controls), then export with "Create PDF form" checked.

## Mail Merge

Tools → Mail Merge Wizard. Connect a spreadsheet as a data source. Insert fields like "Name" and "Address" into your document template. Generate personalized letters, labels, or emails in bulk.

## Essential Shortcuts

- **F11** — Styles panel
- **Ctrl+F2** — Insert fields
- **Ctrl+Shift+Space** — Non-breaking space
- **F12** — Numbering on/off
