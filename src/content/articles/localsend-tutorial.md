LocalSend is the AirDrop alternative that actually works across platforms. Mac, Windows, Linux, iOS, Android — they all talk to each other.

<!-- app:localsend -->

## How It Works

LocalSend uses your local network (Wi-Fi or Ethernet) to transfer files directly between devices. Nothing goes through the internet. No accounts, no cloud, end-to-end encrypted.

## Setup

Install on both devices:

```bash
brew install --cask localsend
```

On mobile, get it from the App Store or Google Play. Both devices need to be on the same network.

## Sending Files

1. Open LocalSend on both devices
2. On the sending device, select files (or text, or clipboard)
3. Tap the receiving device (it appears automatically)
4. Accept on the receiving device

That's it. No pairing, no codes, no cloud.

## Why Not AirDrop?

AirDrop is great — when it works, and when you're in the Apple ecosystem. LocalSend works between any combination of devices. iPhone to Windows laptop? Yes. Android to Mac? Yes. Linux to anything? Yes.

## Pro Tip

Keep LocalSend running in the background (enable "Launch at login"). It uses negligible resources and makes file transfers instant whenever you need them.
