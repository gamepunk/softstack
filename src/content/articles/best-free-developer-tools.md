The modern developer's toolkit doesn't need to cost anything. Here's the complete free stack.

<!-- app:visual-studio-code -->
## VS Code — Code Editor

The dominant code editor. Extension marketplace, integrated Git, terminal, debugger. Free and open-source.

<!-- app:iterm2 -->
## iTerm2 — Terminal (Mac)

Split panes, powerful search, profiles, and tmux integration. The terminal macOS should have shipped with.

<!-- app:docker-desktop -->
## Docker — Containers

Run applications in isolated containers. Includes Kubernetes, Compose, and a management dashboard. Free for personal use.

<!-- app:postman -->
## Postman — API Client

Build, test, and document REST, GraphQL, and WebSocket APIs with a visual interface. The free tier is substantial.

<!-- app:dbeaver -->
## DBeaver — Database GUI

Universal database client that connects to MySQL, PostgreSQL, SQLite, MongoDB, and dozens more. Free Community edition.

<!-- app:rectangle -->
## Rectangle — Window Manager (Mac)

Keyboard shortcuts for snapping windows. Free, open-source, zero configuration.
