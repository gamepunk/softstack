Penpot is the open-source alternative to Figma. Every feature is free forever, no paywalls.

<!-- app:penpot -->

## Getting Started

Sign up at penpot.app (free cloud) or self-host. Create a team, then a project. Inside a project, create a file. The interface has the canvas in the center, layers panel on the left, design panel on the right, and toolbar at the top.

## Drawing and Layout

Penpot uses open web standards natively — everything is SVG, CSS, and HTML under the hood. The layout tools are built around Flexbox and CSS Grid. Create auto-layout frames that reflow content when resized. Components (reusable design pieces) work with variants and overrides.

## Prototyping

Switch to Prototype mode (tab at top). Connect frames with interaction lines. Set triggers (click, hover, delay) and actions (navigate, overlay, toggle). Preview in Presentation mode. Share a link for stakeholders to view and comment.

## Collaboration

Invite team members. Real-time multiplayer — see others' cursors and changes live. Comments on the canvas for design reviews. Library of shared components across projects.

## Key Differences from Figma

- **Fully open-source** — Self-host, no vendor lock-in
- **Web standards** — Flexbox and Grid instead of proprietary layout
- **No limits** — Unlimited files, pages, and viewers on the free plan
