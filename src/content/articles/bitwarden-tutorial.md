Bitwarden is the free, open-source password manager that offers unlimited passwords across unlimited devices.

<!-- app:bitwarden -->

## Installation

```bash
brew install --cask bitwarden
```

Also install the browser extension for autofill. Create an account (email + master password — make it strong, make it memorable).

## Importing Passwords

If you've been using Chrome or another browser to save passwords:

1. Export from your browser (Settings → Passwords → Export)
2. In Bitwarden: Tools → Import → choose the format
3. Upload the file

## Daily Use

- **Cmd/Ctrl+Shift+L** — Auto-fill the current site
- **Cmd/Ctrl+Shift+Y** — Open the vault popup
- Click the Bitwarden icon in form fields to fill

The browser extension detects login forms and offers to save new passwords automatically.

## Generating Strong Passwords

Click the "Generate" button in the extension. You can set length, character types, and whether it's a passphrase.

## Sharing (Free)

Create an Organization (free for 2 users) to share passwords with a partner or family member. Each person has their own master password; shared items sync automatically.

## Why Not Your Browser?

Browser password managers are convenient but tie you to one browser and one platform. Bitwarden works everywhere — any browser, any device, with the same vault.
