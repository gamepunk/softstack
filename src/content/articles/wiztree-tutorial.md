WizTree scans your drive in seconds and shows exactly what's eating your space.

<!-- app:wiztree -->

## Quick Scan

Open WizTree (as Administrator for full scan). Select a drive — it scans in 2-5 seconds. The treemap on the right visualizes every file as a colored rectangle proportional to its size. Larger blocks = larger files. Click any block to jump to that file in the tree view.

## What to Delete

Sort by "Size" in the tree view (left panel). Common space hogs:
- `C:\Windows\Temp` — Temporary files, safe to delete
- `AppData\Local\Temp` — Application temp files
- Old browser caches
- `Downloads` folder
- Old Windows update files

Right-click any folder → Open in Explorer to verify before deleting.

## File Type Analysis

View → File View or press F9. See which file types consume the most space. Great for finding accumulated `.mp4`, `.iso`, or `.zip` files scattered across folders.

## Top Files

View → Top Files. Shows the 1000 largest files on the drive. Sort by size descending. Quickly identify forgotten downloads, videos, or disk images.

## Export and Compare

File → Export to CSV. Scan again later and compare reports to see what grew. WizTree is so fast you can scan daily without feeling the time cost.
