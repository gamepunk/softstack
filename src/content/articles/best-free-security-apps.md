You don't need to pay for basic digital security. These free tools cover password management, VPN, encryption, and anonymous browsing.

<!-- app:bitwarden -->
## Bitwarden — Password Manager

Bitwarden is the free, open-source password manager that offers unlimited passwords across unlimited devices — something no competitor matches at zero cost. Browser extensions, desktop apps, mobile apps, and CLI all sync seamlessly. Passkeys and TOTP generation included.

<!-- app:keepassxc -->
## KeePassXC — Offline Password Manager

For those who don't trust the cloud, KeePassXC stores passwords in an encrypted local database you control. Browser integration, TOTP codes, and YubiKey challenge-response are all built in.

<!-- app:tor-browser -->
## Tor Browser — Anonymous Browsing

Tor Browser routes your traffic through the Tor network, blocking trackers and fingerprinting. Based on Firefox ESR, it feels like a normal browser but with serious privacy protections.

<!-- app:protonvpn -->
## Proton VPN — Free VPN

Proton VPN's free tier is genuinely free: no ads, no logs, no bandwidth limits. Run by the same Swiss nonprofit behind Proton Mail, with a proven track record on privacy.

## Quick Setup

```bash
# Bitwarden
brew install --cask bitwarden

# KeePassXC
brew install --cask keepassxc

# Tor Browser
brew install --cask tor-browser

# Proton VPN
brew install --cask protonvpn
```
