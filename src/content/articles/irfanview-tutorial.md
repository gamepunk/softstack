IrfanView is the legendary Windows image viewer. Here's how to use its best features.

<!-- app:irfanview -->

## Essential Shortcuts

| Key | Action |
|-----|--------|
| Space/Backspace | Next/Previous image |
| +/- | Zoom |
| F | Fullscreen |
| T | Thumbnails view |
| Ctrl+R | Rotate right |
| Ctrl+Y | Crop (select first with mouse) |
| Ctrl+S | Save |
| B | Batch conversion |

## Batch Conversion

File → Batch Conversion/Rename (or press B). Add images, choose output format, set options (quality, resize). Click Start Batch. Ideal for resizing photos for email, converting formats, or adding watermarks.

Batch rename: Use the "Batch rename" tab to rename hundreds of files with patterns like `vacation_###`.

## Thumbnail Browsing

Press T or File → Thumbnails. Browse folders as image grids. Drag to rearrange. Select multiple thumbnails and batch operate on them (convert, rename, copy to folder).

## Slideshows

File → Slideshow. Add images, set delay (3-5 seconds), transitions, and background music. Save as EXE or SCR (screensaver).

## Plugins

Install the plugin pack from irfanview.com — adds support for 50+ formats including HEIC, WebP, RAW camera formats, and video playback. Without plugins, IrfanView is fast. With plugins, it opens everything.
