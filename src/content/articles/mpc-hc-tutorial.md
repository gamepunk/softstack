MPC-HC is the no-frills video player that plays everything with zero overhead.

## Why MPC-HC?

It launches instantly, plays every format, and uses almost no resources. The interface is Windows Media Player 6-style — utilitarian but efficient. No library, no metadata, no login. Just a window that plays video.

## Keyboard Controls

| Key | Action |
|-----|--------|
| Space | Play/Pause |
| F | Fullscreen |
| ← → | Seek short |
| Ctrl+← → | Seek medium |
| Shift+← → | Seek long |
| ↑ ↓ | Volume |
| M | Mute |
| S | Stop |
| O | Open file |
| F5 | Save image |
| Ctrl+E | Next audio track |
| S | Toggle subtitles |

## Playback Options

Right-click → Options → Playback. Enable "Remember last window position" and "Remember last window size." Under "Output," select "Enhanced Video Renderer (custom presenter)" for best quality on modern Windows.

## Subtitles

Drag subtitle files onto the player window. Options → Subtitles → Default Style to set font and size. The subtitle delay (F1/F2) adjusts sync while watching — F1 to delay subtitles by 100ms, F2 to advance them.

## Playlist

View → Playlist (Ctrl+7). Drag multiple files. Use shuffle (Ctrl+Shift+S). Save playlists as `.mpcpl` files. The player remembers the last open playlist on restart.
