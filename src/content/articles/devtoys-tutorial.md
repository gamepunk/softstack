DevToys bundles 30+ developer utilities into one free, offline app.

<!-- app:devtoys -->

## Top Tools

**JSON/YAML Converter** — Paste JSON, get formatted/validated output. Convert between JSON and YAML. Minify, escape, and unescape.

**Regex Tester** — Write a regex pattern, paste test text, see matches highlighted in real-time. Cheatsheet included for common patterns.

**JWT Decoder** — Paste a JWT token, see the decoded header and payload. Useful for debugging auth tokens.

**Hash Generator** — Generate MD5, SHA-1, SHA-256, SHA-512 hashes from text or files. Verify checksums.

**Text Diff** — Compare two texts side by side with highlighted differences. Simpler than a full diff tool for quick comparisons.

**UUID Generator** — Generate UUIDs in different formats. Batch generate with a count.

**Base64 Encoder/Decoder** — Encode/decode Base64 text and images.

## Settings

All processing is offline — no data leaves your machine. Settings → enable "Smart Detection" to auto-identify input types (e.g., JWT tokens auto-open in the JWT decoder).
