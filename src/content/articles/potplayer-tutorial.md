## Essential Shortcuts

| Key | Action |
|-----|--------|
| Space | Play/Pause |
| ← → | Seek 5 seconds |
| ↑ ↓ | Volume |
| Enter | Fullscreen |
| F5 | Settings |
| F7 | Playlist |
| F12 | Capture screenshot |
| A | Aspect ratio cycle |
| S | Subtitle on/off |
| Alt+E | Video capture |

## Hardware Acceleration

F5 → Video → Video Renderer. Choose "Enhanced Video Renderer" for most systems, or "MadVR" for advanced upscaling. F5 → Filter Control → Video Decoder: enable "DXVA2 Copy-Back" for hardware-accelerated decoding.

## Subtitle Management

PotPlayer supports every subtitle format. Right-click → Subtitles → Add/Select subtitles to load external files. Alt+S toggles. F5 → Subtitles → adjust font, size, position, and sync offset. Right-click → Subtitles → Subtitle Browser searches and downloads subtitles directly.

## Bookmarks

Press P to add a bookmark. Press H to show the bookmark list. Right-click → Playback → Chapter/Bookmark. Useful for marking scenes in long videos. Bookmarks save with the filename.

## Advanced Features

- **A-B Repeat:** Press [ to set start, ] to set end. Loops the selected segment.
- **Scene Browser:** Ctrl+Alt+B shows thumbnails of the video at intervals. Click to jump.
- **Screen Capture:** F12 captures current frame. Alt+C captures as a GIF.
