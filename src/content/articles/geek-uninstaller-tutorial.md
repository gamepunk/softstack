Geek Uninstaller is a tiny, portable tool that removes programs and their leftover files.

<!-- app:geek-uninstaller -->

## Basic Uninstall

Download and run (no installation needed). It lists all installed programs with size and install date. Right-click a program → Uninstall. Geek Uninstaller runs the program's own uninstaller, then scans for leftover files, folders, and registry entries. Review and delete them.

## Force Removal

If a program refuses to uninstall (corrupted installer, missing files, etc.), right-click → Force Removal. Geek Uninstaller aggressively removes all traces of the program using its own scan. Use this for stubborn entries that Windows Add/Remove Programs can't handle.

## Removing Windows Store Apps

View → Windows Store Apps. Geek Uninstaller lists all Microsoft Store apps. Right-click → Uninstall to remove bloatware or apps that can't be uninstalled normally (like some pre-installed Windows apps).

## Startup Management

View → Startup. See every program that launches at Windows startup. Right-click → Disable to prevent auto-start. Much clearer than digging through Task Manager.

## Tips

- Sort by "Size" to find space-hogging programs
- Sort by "Install Date" to find recently installed suspicious software
- Use "Entry" → "Lookup on Google" to research unknown programs
