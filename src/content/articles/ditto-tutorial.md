Ditto saves everything you copy and makes it searchable. You'll wonder how you lived without it.

<!-- app:ditto -->

## Basic Use

Install and Ditto runs in the system tray. Copy things normally — Ditto saves them all. Press Ctrl+` (default hotkey) to open the history window. Double-click any entry to paste it at the cursor position. Search at the bottom to filter history.

## Organizing Clips

Right-click entries → Add to Group. Create groups like "Emails," "Code snippets," "Addresses." Assign hotkeys to specific groups for instant access. Pinned clips stay at the top and are never deleted.

## Sync Across Devices

Options → Sync. Point Ditto to a shared folder (Dropbox, network drive). Multiple computers can share the same clipboard history. Changes sync automatically.

## Special Paste

Right-click a clip → Special Paste:
- **Paste as plain text** — Strip formatting
- **Paste uppercase/lowercase** — Change case
- **Send via email** — Opens your email client with the text

## Settings

- **Maximum saved entries** — Default 500. Increase if you're a heavy copy-paster
- **Expire entries** — Auto-delete clips older than X days
- **Excluded apps** — Don't save copies from password managers or sensitive apps

Ditto preserves all formatting (rich text, images, files). Search works even for content inside formatted clips.
